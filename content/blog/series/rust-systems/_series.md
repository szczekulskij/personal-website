## About this series

This series documents my path from Rust beginner to implementing distributed systems, following a structured curriculum:

1. **The Rust Book** - Learning Rust fundamentals via [The Rust Programming Language](https://doc.rust-lang.org/book/)
2. **TP 201: Practical Networked Applications in Rust** - Building a high-performance, networked, parallel and async key/value store from scratch ([source](https://github.com/pingcap/talent-plan/tree/master/courses/rust))
3. **TP 202: Distributed Systems in Rust** - Implementing Raft consensus and Percolator transactions, adapted from MIT 6.824 ([source](https://github.com/pingcap/talent-plan/tree/master/courses/dss))
4. **TP 301/302: Distributed Database (TinySQL + TinyKV)** - Building a full distributed relational database and KV store in Go ([TinySQL](https://github.com/tidb-incubator/tinysql), [TinyKV](https://github.com/tidb-incubator/tinykv))

Why am I learning this? Rust is becoming the language of choice for high-performance systems infrastructure. Combining language mastery with hands-on distributed systems implementation is the most effective way to deeply understand both the language and the problem domain.
